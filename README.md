# 🛡️ MarketSentinel AI - Advanced Stock Dashboard

A premium, high-frequency market intelligence dashboard built with Refined Glassmorphism and AI-driven sentiment analysis.

## ✨ Features

- **🚀 Real-Time Market Overview**: Dynamic stock tracking with live price action and automated sorting.
- **🧠 AI Sentiment Engine**: Multi-layered analysis of news and social momentum (Bullish/Bearish/Neutral).
- **📊 Advanced Data Visualization**: Interactive charts for price movement and sentiment trends.
- **📰 Intelligence Feed**: Curated news intelligence with per-item impact scoring.
- **⚡ Performance First**: Optimized React hook-based data polling and state management.
- **🎨 Premium UI**: Deep glassmorphism, neon glow effects, and micro-interactions.

## 🛠️ Architecture

- **Frontend**: React + TypeScript + Tailwind CSS
- **State Management**: Custom `useMarketData` hook with intelligent polling.
- **Styles**: Custom CSS utility layer for glassmorphism and neon glows.
- **Backend Service**: Integrated with Render-hosted FastAPI service for real-time aggregation.

## 🚀 Development Journey

Developed over a 6-week simulated sprint (Feb 3 - Mar 18, 2026), this project demonstrates:
1. **Modular Architecture**: Clean separation of UI cards, data hooks, and utility layers.
2. **Refined UX**: Emphasis on responsiveness, hover interactions, and documentation tooltips.
3. **Robust Git History**: A realistic evolution from early cleanup to production-grade features.
